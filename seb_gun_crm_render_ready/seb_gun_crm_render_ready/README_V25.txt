seb_gun CRM v25.0 — пакет обновления
=====================================

Куда копировать в текущем GitHub-репозитории:
seb_gun_crm_render_ready/seb_gun_crm_render_ready/

Заменить:
- server.js
- package.json
- public/app.js
- public/api.js
- public/styles.css
- public/index.html
- public/sw.js

Не трогать:
- .env.local / секреты Render
- data/quick_phrases.json
- data/services.json
- render.yaml

Что добавлено / исправлено:
1. Ответ на сообщение VK (reply_to).
2. Пересылка сообщения в другой диалог / VK ID (forward_messages).
3. Расшифровка голосового показывается, если VK вернул transcript.
4. Кнопка «⧉» копирует всю историю диалога в формате:
   [31.08.2026 12:08] Имя: Текст
   Голосовые добавляются с расшифровкой, когда она доступна.
5. Одна логика «Назад» для кнопки CRM, браузера и телефона через History API.
6. Поиск/фильтры Диалогов, Клиентов и Напоминаний сохраняются в URL и восстанавливаются после Back/Forward.
7. Активные фильтры отображаются рядом с верхним поиском.
8. Быстрые фразы ищутся без учёта регистра, по названию, группе и полному тексту скрипта; ё/е нормализуются.
9. Мобильная клавиатура/viewport: чат не должен перерисовываться при открытии клавиатуры.
10. Глобальный индикатор загрузки больше не блокирует весь интерфейс.
11. HTTP-запросы имеют таймаут, чтобы «Загрузка…» не висела бесконечно.
12. BlueSales очередь быстрее отдаёт понятную ошибку вместо многоминутного зависания.
13. Заказы: 20 записей по умолчанию, кэш 60 секунд, retry при ошибке.
14. CRM-шторка открывается сразу; тяжёлые данные догружаются в фоне.
15. Услуги ищутся регистронезависимо и по нескольким словам.

Проверка после deploy:
- Ctrl+Shift+R на ПК.
- На телефоне закрыть старую вкладку; при необходимости очистить данные сайта/PWA-кэш.
- Проверить Reply, Forward и расшифровку на реальном VK: поддержка transcript зависит от того, возвращает ли VK расшифровку для конкретного голосового.

Локальные проверки пакета:
- npm run check
- npm run test:v25
