seb_gun CRM v27.0 — stable mobile kernel

Цель версии: перестать латать чат точечными full-render исправлениями и изолировать самые болезненные состояния интерфейса.

Основные изменения:
1. Диалоги: первая страница загружается быстро; остальные страницы догружаются последовательно в фоне. Ручной кнопки «Загрузить ещё» для диалогов нет.
2. Черновики v2: текст скрипта + вложения имеют revision counter. Старый DOM больше не может перезаписать более новый сохранённый черновик. Есть миграция с v1 localStorage.
3. Android/iOS фильтры: вместо длинного выпадающего меню используется bottom sheet. Список прокручивается отдельно, а «Сбросить / Применить» всегда закреплены снизу с safe-area.
4. Мобильный чат: фоновое завершение BlueSales hydration не вызывает full render всей переписки. Это убирает один из основных источников прыжков scroll и мерцания composer.
5. Polling списка диалогов обновляет только список, а не всю страницу.
6. Render restart: BlueSales API-сессия может восстановиться из зашифрованной HttpOnly cookie. В cookie нет plaintext пароля; хранится только passwordHash, нужный API. Это снижает количество внезапных 401 после перезапуска Render.
7. Сохранены: VK, BlueSales, Telegram SLA, 151 скрипт, голосовые/фото/видео attachments, защита от дублей отправки, расшифровки и единый CRM timezone.

Важно:
- Для усиления защиты зашифрованной session cookie можно задать SESSION_SECRET в Render Environment. Если не задан, v27 использует стабильный server-side key derived from preset VK token.
- Полный Chatwoot/Twenty не встраивался как зависимость: это значительно увеличило бы количество runtime-компонентов на Render Free. v27 переносит проверенные state/UI patterns в текущий лёгкий Node stack.
