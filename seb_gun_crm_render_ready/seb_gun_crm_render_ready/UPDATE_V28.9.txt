seb_gun CRM v28.9 — Telegram для всех менеджеров

Что изменилось

1. Один Telegram-бот теперь обслуживает любое количество менеджеров.
2. Каждый менеджер подключает собственный Telegram через CRM.
3. Для нового получателя фильтр «Менеджеры лидов» автоматически выбирает этого же менеджера. Поэтому ему приходят только его лиды, если администратор не изменит фильтр вручную.
4. У каждого получателя остаются свои настройки: фильтр, CRM-статусы, SLA, рабочее время и повторы.
5. Администратор может скопировать все подключения одной кнопкой и сохранить их в Render в переменной NOTIFICATION_RULES_JSON.
6. После перезапуска бесплатного Render привязки восстанавливаются из NOTIFICATION_RULES_JSON.

Важно

- TELEGRAM_BOT_TOKEN общий для проекта, но telegramChatId у каждого менеджера свой.
- NOTIFICATION_DEFAULT_MANAGER и NOTIFICATION_DEFAULT_CHAT_ID оставлены только для совместимости со старой настройкой одного получателя.
- SLA считается в рабочих минутах по настройкам правила. Значения по умолчанию: 10:00–22:00, Europe/Moscow, 8 минут.
- В бесплатной схеме GitHub Actions запускает проверку примерно раз в 15 минут. Для гарантированной проверки ровно через 8 минут нужен постоянно работающий сервер или отдельный worker/cron с более частым запуском.
