seb_gun CRM v25.3

Что изменено:
- Голосовые: сначала используется расшифровка VK, затем Groq Whisper fallback.
- Для Groq сначала передается URL голосового напрямую; если CDN VK не разрешит внешний доступ, сервер скачивает аудио и отправляет файл.
- Копирование всего диалога догоняет отсутствующие расшифровки голосовых (до 40 за один экспорт, concurrency 2).
- Быстрые фразы запоминают поиск, точную позицию, последний и несколько недавних скриптов.
- Поиск фраз не зависит от регистра, нормализует ё/е и ищет по группе, названию и полному тексту.
- На мобильном: свайп от левого края открывает быстрые фразы, от правого — CRM-карточку. Оставлен небольшой системный край под Back gesture ОС.
- Шторки включены в History API: браузерные/системные Назад и Вперёд закрывают/возвращают шторку и сохраняют экран.
- Загрузка не блокирует приложение; есть watchdog от вечного спиннера.
- BlueSales: уменьшены ожидания очереди/retry, отложена CRM-гидратация списка диалогов, добавлен stale cache.
- Услуги кэшируются дольше, заказы используют короткий cache + stale fallback.

Расшифровка:
1. Создать API key в Groq Console.
2. Render -> seb-gun-crm -> Environment -> GROQ_API_KEY = секретный ключ.
3. Не добавлять ключ в GitHub и не отправлять его в чат.
4. После deploy открыть /api/health и проверить sttConfigured: true.

Если GROQ_API_KEY не задан, CRM продолжит использовать только расшифровку VK.
