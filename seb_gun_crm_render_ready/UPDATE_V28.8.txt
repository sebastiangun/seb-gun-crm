seb_gun CRM v28.8
=================

1. Фото после отправки сразу видно в диалоге. Локальное сообщение остаётся на экране со статусом очереди/отправки, затем чат несколько раз синхронизируется с VK.
2. Диалоги больше не догружают десятки страниц автоматически. Сначала показываются 50, затем по кнопке — ещё 75. Это уменьшает зависания и ошибки 502 на бесплатном Render.
3. Исправлен поиск быстрых фраз: поиск по разделу, названию, тексту, горячей клавише, менеджеру и вложению; данные обновляются при каждом открытии шторки.
4. Администратор может отдельно создать новую фразу и новый раздел.
5. Telegram-настройка может восстанавливаться из Render Environment после сна/перезапуска сервиса.
6. Команда /id в боте показывает Telegram chat ID.
7. В «Уведомлениях» видны готовность фоновой проверки, недостающие переменные и время последнего запуска.
8. В архив добавлен GitHub Actions workflow .github/workflows/crm-notifications.yml. Он будит бесплатный Render и вызывает защищённую проверку раз в 15 минут в интервале 10:00–22:00 МСК.

ВАЖНО
Бесплатный Render засыпает без входящих запросов. Внутренний таймер Node.js во сне не выполняется. Workflow GitHub Actions является обходным вариантом, но его запуск может задерживаться, а уведомление придёт при ближайшей 15-минутной проверке. Для строгого SLA 8 минут нужен постоянно работающий сервер и постоянное хранилище.
