КАК УСТАНОВИТЬ v28.15 НА RENDER

1. Распакуйте архив.
2. В GitHub откройте репозиторий seb-gun-crm.
3. Загрузите содержимое папки seb_gun_crm_render_ready с заменой существующих файлов.
4. Сделайте commit в ветку main.
5. Render Blueprint автоматически запустит сборку. Дождитесь статуса Live.

Проверка после публикации:
- в разделе «Ещё» должна отображаться версия v28.15 Vue;
- создайте тестового клиента из VK-диалога только один раз;
- откройте «Уведомления» и нажмите «Проверить сейчас»;
- в журнале должны отображаться входящее сообщение, ответ, даты, статус и цепочка менеджеров;
- проверьте фильтры «Менеджеры», «Статусы», «Дата от» и «Дата до».

Если создание клиента снова вернёт ошибку, скопируйте из Render Logs строки
[BlueSales customers.addMany] и [BlueSales API details]. В v28.15 повторный
изменяющий запрос намеренно не выполняется, поэтому дубль не создаётся.
