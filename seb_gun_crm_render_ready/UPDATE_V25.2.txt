seb_gun CRM v25.2

Добавлено:
- VK transcript -> Groq Whisper fallback для голосовых сообщений.
- GROQ_API_KEY хранится только в Render Environment.
- Позиция/поиск/последний скрипт в левой шторке сохраняются в localStorage.
- Свайп от левого края открывает скрипты, от правого края — CRM-карточку; обратный свайп закрывает.
- Поиск скриптов регистронезависимый, ё=е, ищет по группе, названию и тексту.
- Услуги кэшируются 5 минут, заказы — кратко на клиенте; одинаковые GET не дублируются.
- Глобальная загрузка заменена на тонкий индикатор сверху; polling раз в 45 секунд.
- История браузера остаётся через History API + URL-фильтры из v25.1.

Для гарантированной расшифровки добавьте в Render Environment секрет GROQ_API_KEY.
