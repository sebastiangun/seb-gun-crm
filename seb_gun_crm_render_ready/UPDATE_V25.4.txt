seb_gun CRM v25.4

1) Голосовые сообщения
- Убрана зависимость от VK transcript API и любых облачных STT-ключей.
- Локальная расшифровка через open-source GitHub-проект huggingface/transformers.js + Xenova/whisper-tiny.
- Аудио берётся из уже полученной ссылки вложения, декодируется open-source audiojs/decode (OGG/Opus/MP3 и др.) и обрабатывается в Worker Thread.
- Endpoint расшифровки НЕ вызывает VK transcript API; VK используется только как место, где физически хранится исходный аудиофайл.
- На Render не нужен отдельный API-ключ для STT.
- Первый запуск расшифровки после холодного старта дольше, потому что модель загружается и кэшируется.

2) Быстрые фразы
- Последний скрипт, поиск и прокрутка сохраняются для конкретного аккаунта.
- При повторном открытии шторка возвращается к последнему скрипту.
- Поиск без регистра, с нормализацией ё/е, по разделу, названию и полному тексту.

3) Телефон
- Свайп слева -> быстрые фразы; свайп справа -> CRM-карточка.
- Добавлены маленькие боковые ручки, если жест неудобен.
- Системный Back и браузерные Back/Forward используют History API; двойные события history дедуплицируются.

4) Производительность
- STT работает в отдельном worker thread и не блокирует основной HTTP event loop.
- Фоновый polling снижен до 60 секунд.
- Сохраняются дедупликация GET, stale-cache услуг/заказов и очередь BlueSales из v25.3.
- Каталог услуг предзагружается в фоне при открытии CRM-шторки.
- Заказы кэшируются дольше и больше не вызывают лишнюю полную перерисовку чата при старте загрузки.
- UI-watchdog снимает зависший глобальный индикатор примерно через 24 секунды.
